## Top 3 cases for DDCT
1. **Lecture-jam sandwich (Falk & Inie 2022)** — pre-jam AI primer → voluntary, non-competitive 7-day AI jam → Discord mentors + Expo peer vote; prototypes ungraded on functionality. Validated by expert consensus + Schön theory (no outcome numbers, n=3). Strengthens S4 3-week blocks / S5-L3, L8, L3, DR23; runnable as the year-1 pilot block with no new infrastructure.
2. **AI-fills-the-artist-seat jam (Bezzina & Dingli 2024)** — formal jam configuration change (GenAI replaces graphic-design students) + 19-question survey. Measured: n=37; 45.9% learning gains, 56.7% reuse intent, reliability 2.16/5, 48.6% "slightly worse" assets, communication 83.7% effective. Strengthens S4/S5-L3, DR1/DR9 (AI for static assets; humans for sprites/QC), L6; reusable assessment instrument for DDCT's own cohort.
3. **Prompt design patterns + AI-on/AI-off alternation (Alharthi 2026)** — three named patterns taught as explicit curriculum; reflection moments deliberately interrupt automation. n=113, qualitative (prompt-iterators engage more deeply; no quantitative outcomes). Strengthens S0 AI-Fluency core course, DR24 assessment integrity, DR3 skill-atrophy countermeasure, L3.
