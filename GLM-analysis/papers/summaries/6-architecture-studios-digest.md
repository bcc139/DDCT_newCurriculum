## Top 3 cases for DDCT
1. **20h dual-module retrofit + dedicated technical instructor (Zhejiang)** — 20 class-hours AI skills + ethics threads inside existing crits, 1 technical instructor, cloud model lab, live syllabus updates. Measured: 95.7% beneficial (n=70), embedded ethics preferred 2:1, but only 5.9% frequent use → pair rollout with phase-sensitive scaffolding. Strengthens S0/DR24/L7/L4/DR12.
2. **Design-log studio (Sejong)** — 9-field per-stage log + shared whiteboard + accreditation rubric; process graded, not just renders. Measured: CSI 66.58; r≈0.96 self–tutor; fundamentals (Function/Performance/Safety) unchanged → protect them explicitly. Strengthens L3/DR23/L6/L5.
3. **Phase-sequenced AI legitimacy + prompt traces in crit (Iranmanesh synthesis)** — green-light AI breadth early, demand justification + disclosure at resolution; prompt journal as crit artifact. Synthesis only (no effect sizes) but gives the operational rule for the 3-zone policy. Strengthens S0 3-zone/DR23/DR16.

## Notes
Small/weak designs throughout (n=70, 12, 16, 72; no RCTs, no effect sizes). Usage (paper 1: peaks upstream, 62.9% design dev vs 31.4% representation) vs perceived support (paper 2: peaks mid/late) measure different things — pilot both. Paper 4 predates GenAI literature. Venues of papers 3–4 unrecoverable from converted text. All architecture; adapt "representation phase"→art milestone, "function/safety"→technical requirements for DD/CT.
