## Top 3 cases for DDCT

1. **8-prompt course-rebuild protocol** (2025 ChemE) — faculty rebuild syllabus/materials/assessments via fixed prompts; measured via reflections: syllabi + ABET maps + case studies = clear time savings, assessments = net loss. Strengthens **S0 + L7**: run it as a DDCT faculty redesign sprint with program-outcome mapping swapped in.
2. **AI-contextualized, expert-verified problem generation** (2026 ME) — same numbers/physics wrapped in real-world narrative; performance 6.62 vs 3.31 (p=0.003), workload flat, preference reversed. Strengthens **L1, L6, DR23**: prompt protocol + expert verification as a copyable assessment workflow for problem-based DD/CT courses.
3. **Perception baseline + skepticism→strategy conversion arc** (2025 ChemE, n=78) — adoption 87–92%, trust low, limitations-awareness 4.4–4.5, students explicitly request clear AI rules. Strengthens **DR7** (DDCT's AI-skeptics convert through guided use), **DR23/3-zone policy**, **DR3** (first-person atrophy evidence for the Brake·Anchor·Engine counterweight).

## Gaps
- Both 2024 papers: zero numbers; named deployments (Berkeley/MIT/Michigan) second-hand and uncited.
- No learning-outcome measurement in the 2025 rebuild (no grade comparisons); 2026 study n=14, gender-imbalanced, GPT-3.5 (Feb 2024), fixed problem order, preference effect fails the nonparametric check.
- Key tension: students perform better on AI problems but prefer textbook ones — supports fundamentals-first + AI-context layering.
- All US engineering, text-only ChatGPT: no art/design disciplines, no generative media, no Thai/SEA context, no local/NDA-safe models.
