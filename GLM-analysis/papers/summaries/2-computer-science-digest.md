## Top 3 cases for the DDCT curriculum

1. **CS50 guardrailed tutor + human-feedback loop (papers 3+7)** — RAG over course materials, guardrails, throttling, human endorsement; then a 50-conversation fine-tune judged by TF arena evals. Measured: 88% accuracy vs 48% baseline, 86% approval, $1.50/student/yr at 211k users, ~60% win rate over baseline tutor, model-graded eval matches humans 82%. Strengthens S0 (AI-Fluency core, local-model lab), DR23, L1/L5 — DDCT builds a "studio duck" over DigiPen course content with a staff-curated alignment set and per-model-update regression checks.
2. **Cognitive engagement beats delegation (paper 12)** — RCT showing AI access costs 17% of learning (d=0.738) unless students use Conceptual-Inquiry or Generation-Then-Comprehension patterns (65–86% vs 24–39% quiz). Strengthens DR3, L3, AI-as-junior-staff loop — codify the winning patterns as graded 🟢-zone studio protocol (judgment notebook: ask-why, critique-before-adopt) and keep 🔴 AI-free fundamentals blocks.
3. **Dual-mode + process-visible assessment (paper 10)** — AI-free then AI-assisted phases graded separately; 20% code / 30% prompt log / 50% reflection weighting (fairness 4.4–4.6/5); capstone graded on spec + verification suite + interaction log + prototype; planning hints the only performance-linked scaffold. Strengthens DR23, L3, DR9 — a ready-made grading contract for the 3-zone policy that scores process and verification, not just the artifact.
