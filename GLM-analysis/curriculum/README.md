# Curriculum & syllabus reference collection — for the DDCT new-curriculum work

Collected 2026-10-14 (updated same day: DigiPen full campus family + Greater-China + HK). Reference programs and
course syllabi to inform the DDCT (DD + CT) AI-era curriculum redesign — groundwork for the all-faculty meeting
this month ("know what others do, then decide what DDCT does differently"). Scenario/DR/L codes refer to the
working group's `../02-curriculum-scenarios.md` and evidence lessons (`../05-evidence-ai-curriculum-integration.md`).
Chinese-language documents can be translated/summarized on request (ask in any ZCode session).
